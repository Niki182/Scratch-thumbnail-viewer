# Scratch-thumbnail-viewer
This website is made by me (Niki182) as a hobby project

# How this website works
This website uses `uploads.scratch.mit.edu` to fetch the thumbnail images.
This website also uses `api.scratch.mit.edu` to fetch the name and the profile picture of the project creator
